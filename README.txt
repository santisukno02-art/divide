รองรับค่าอาหารรายคน ส่วนลดอาหารแบบบาท/เปอร์เซ็นต์พร้อมเพดาน ส่วนลดกลุ่ม ค่าส่ง และส่วนลดค่าส่ง
แบ่งค่าส่งและส่วนลดกลุ่มแบบเท่ากันหรือตามสัดส่วนได้
ทุกคนจ่ายเป็นจำนวนเต็มบาท โดยจัดสรรบาทที่เหลือให้คนที่มีเศษมากก่อน หากเศษเท่ากันใช้ลำดับรายชื่อ
ตัวอย่าง ยอด 100 บาทหาร 3 คน = 34, 33, 33 บาท
หากยอดบิลมีสตางค์ ปัดยอดรวมขึ้นเป็นบาทเต็ม เช่น 100.25 บาท เรียกเก็บ 101 บาท แสดงส่วนต่าง 0.75 บาท
มีปุ่มคัดลอกสรุปบิล และจำบิลไว้ในเบราว์เซอร์เครื่องนี้
